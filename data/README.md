# داده‌های محلی

فایل‌های CSV عملیاتی را محلی نگه دارید. مخزن عمومی است. فایل‌های داخل این پوشه به‌جز همین راهنما توسط .gitignore نادیده گرفته می‌شوند؛ با این حال بارگذاری دستی از رابط وب GitHub ممکن است این محافظ را دور بزند. پیش از هر انتشار، محتوا را بررسی کنید.

فرمت ورودی:

```text
received_at_utc,source_time_utc,pair,price_usd
```

هر زمان باید timezone داشته باشد. قیمت عدد مثبت و محدود است. هیچ دادهٔ ساختگی به‌عنوان دادهٔ بازار همراه پروژه منتشر نشده است.
