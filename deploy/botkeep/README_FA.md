# نسخهٔ مستقل شش‌جفتی برای پروژهٔ تازهٔ Botkeep

این پوشه برنامهٔ کامل Python 3.11+ است؛ collector یا فایل‌های ریشهٔ مخزن لازم نیست. تلاش می‌کند قیمت BTC-USD، ETH-USD، SOL-USD، XRP-USD، DOGE-USD و ADA-USD را از API عمومی Coinbase Exchange در چرخهٔ اسمی **60 ثانیه** بخواند. پشتیبانی و دسترسی فعلی هر جفت بررسی زنده نشده است. معامله، سفارش، کیف پول، هوش مصنوعی، Ollama، کلید، رمز و .env ندارد. API فعلی عمومی و بدون کلید است؛ هزینه و محدودیت میزبانی و شرایط سرویس را جدا بررسی کنید. رایگان‌بودن یا تداوم دسترسی تضمین نشده است.

## نصب با اندروید، بدون دست‌زدن به سرور قبلی

1. یک پروژهٔ Python تازه و جدا بسازید؛ سرور قبلی را تغییر ندهید. از کد و CSV و لاگ قبلی پشتیبان بگیرید.
2. Code → Download ZIP مخزن را دانلود و در فایل‌منیجر استخراج کنید. وارد deploy/botkeep شوید. **محتویات پوشه** یعنی main.py، requirements.txt و README_FA.md را مستقیماً در ریشهٔ پروژهٔ تازه بارگذاری کنید؛ خود پوشه یا کل مخزن لازم نیست.
3. راه جایگزین ZIP کوچک: Actions → Package Botkeep → Run workflow روی master. بعد از موفقیت artifact به نام botkeep-upload را دانلود و استخراج کنید؛ اگر botkeep-upload.zip داخل آن بود دوباره استخراج کنید. سه فایل باید در ریشهٔ سرور باشند. گردش کار فقط با اجرای دستی بسته می‌سازد، نه خودکار هنگام انتشار.
4. فایل شروع main.py و فرمان اختیاری python main.py --interval 60 است؛ python main.py نیز همان پیش‌فرض را دارد. Python 3.11+ انتخاب کنید؛ requirements.txt فقط توضیح است و بستهٔ pip لازم نیست.
5. برای آزمایش اختیاری، وقتی اجرای مداوم همین پروژه متوقف است، در ترمینال ریشهٔ پروژه:

```sh
# یک بار هر شش جفت؛ موفقیت‌های جزئی ذخیره و خطا با خروج غیرصفر
python main.py --once
# اجرای مداوم، پیش‌فرض 60 ثانیه
python main.py --interval 60
# گزینهٔ سریع‌تر، نه تضمین نرخ یا دسترسی
python main.py --interval 30
```

دو نسخه را روی CSV یا مسیر خروجی مشترک اجرا نکنید. سرور قدیمی می‌تواند با خروجی جدا ادامه بدهد. کاربر فایل‌ها را خودش به میزبان آپلود می‌کند؛ این مخزن به Botkeep متصل نیست.

## چرخه و خطا

در هر چرخه شش درخواست ترتیبی، با timeout بیست‌ثانیه‌ای برای هر درخواست، ارسال می‌شود. زمان پردازش از فاصله کم می‌شود؛ چرخه‌ها هم‌پوشانی ندارند و عقب‌افتادگی با هجوم جبرانی پاسخ داده نمی‌شود. نرخ واقعی ممکن است به علت شبکه یا محدودیت بیشتر شود. --interval باید مثبت و محدود باشد. دادهٔ جایگزین ساختگی یا قیمت قبلی ذخیره نمی‌شود.

- خطای یک جفت مانع ذخیرهٔ موفقیت‌های بقیه نیست؛ خطای عادی چرخهٔ بعد دوباره امتحان می‌شود.
- HTTP 401، 403 یا 451: توقف کامل؛ محدودیت‌ها را دور نزنید.
- HTTP 404: فقط همان جفت تا پایان اجرا غیرفعال و لاگ می‌شود؛ اگر همه غیرفعال شوند توقف. هیچ دارایی جایگزین نمی‌شود.
- HTTP 429: مکث سراسری حداقل 60 ثانیه، یا بیشتر مطابق Retry-After معتبر. اجرای مداوم ادامهٔ چرخه را به بعد از مکث موکول می‌کند؛ --once پیش از جفت بعدی صبر می‌کند. محدودیت دسترسی می‌تواند --once را زودتر متوقف کند.
- --once در موفقیت کامل خروج 0 و شکست جزئی خروج 1 دارد؛ رکوردهای موفق پاک نمی‌شوند.

## خروجی، تحلیل و پشتیبان

- همان CSV چهارستونی received_at_utc,source_time_utc,pair,price_usd در prices.csv کنار main.py؛ monitor.log نیز همان‌جاست و لاگ روی کنسول دیده می‌شود. پوشه باید قابل نوشتن باشد.
- --output مسیر CSV را تغییر می‌دهد؛ مسیر نسبی نسبت به پوشهٔ کاری است. لاگ کنار main.py باقی می‌ماند. هنگام تغییر نرخ، فایل تازه بگیرید تا دوره‌های 300، 60 و 30 ثانیه مخلوط نشوند.
- CSV در حدود 5MiB به prices.<timestamp>.csv منتقل می‌شود؛ آرشیو خودکار حذف نمی‌شود. لاگ در حدود 1MB می‌چرخد و دو نسخهٔ قدیمی حفظ می‌شود. prices*.csv و monitor.log* را دانلود و فضای دیسک و ماندگاری پس از restart را بررسی کنید.
- تحلیل‌گر در این بسته نیست؛ برای تحلیل آفلاین از tools/analyze_prices.py مخزن استفاده کنید: python tools/analyze_prices.py prices.csv --expected-interval 60. برای CSV قدیمی --expected-interval 300 و برای نرخ 30 مقدار 30 است. JSON جدید gaps_over_threshold_seconds و metadata فاصله دارد؛ آستانه 1.1 برابر فاصله است. فقط جفت‌های حاضر در CSV گزارش می‌شوند.
- اسکریپت وب‌سرور یا پورت شنونده ندارد؛ خودش پورت لازم ندارد. میزبان ممکن است الزام HTTP/health check، محدودیت پس‌زمینه یا منابع داشته باشد؛ سیاست فعلی Botkeep و پذیرش Coinbase برای محل شما تأیید نشده است.
- قیمت نمونه‌برداری‌شده کندل یا عمق بازار نیست؛ نرخ 30 یا 60 ثانیه، آزمون فشار بازار یا پیش‌بینی نوسان یا تضمین سود نیست.
- CSV و لاگ واقعی، توکن، رمز و اطلاعات کیف پول را در مخزن عمومی منتشر نکنید؛ بسته دادهٔ کاربر ندارد.

## وضعیت آزمایش

این نسخهٔ شش‌جفتی در این گفتگو اجرا یا روی Botkeep تست زنده نشده است. Package Botkeep فقط py_compile و ZIP با کتابخانهٔ استاندارد انجام می‌دهد و درخواست قیمت نمی‌فرستد. تست‌های mock در مخزن وجود دارند اما اجراشدن یا موفقیت آن‌ها ادعا نشده است. برای بررسی واقعی باید خود برنامه یا گردش کار دستی تحلیل را اجرا و نتیجه را مشاهده کنید.
