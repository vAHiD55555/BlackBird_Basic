# نسخهٔ مستقل برای پروژهٔ تازهٔ Botkeep

این پوشه یک برنامهٔ کامل Python 3.11+ است؛ به پوشهٔ collector یا فایل‌های ریشهٔ مخزن نیاز ندارد. فقط قیمت BTC-USD را از API عمومی Coinbase Exchange با فاصلهٔ اسمی پنج دقیقه می‌خواند و ذخیره می‌کند. معامله، سفارش، کیف پول، هوش مصنوعی و Ollama ندارد؛ کلید API، فایل .env و رمز لازم نیست. دریافت فعلی از endpoint عمومی بدون کلید است؛ هزینه و محدودیت‌های میزبانی و شرایط سرویس را جدا بررسی کنید. رایگان‌بودن یا دسترسی دائمی تضمین نشده است.

## نصب با اندروید، بدون دست‌زدن به سرور قبلی

1. در Botkeep یک پروژهٔ Python تازه و جدا بسازید؛ فایل‌ها و تنظیمات سرور قبلی را تغییر ندهید. قبل از هر تغییر از کد، CSV و لاگ‌های قبلی پشتیبان بگیرید.
2. در GitHub از Code → Download ZIP استفاده و ZIP را در فایل‌منیجر اندروید استخراج کنید. وارد deploy/botkeep شوید. **محتویات این پوشه** یعنی main.py، requirements.txt و README_FA.md را در ریشهٔ پروژهٔ تازه بارگذاری کنید؛ خود پوشهٔ botkeep یا کل مخزن را بارگذاری نکنید.
3. راه جایگزین ZIP کوچک: در Actions گردش کار Package Botkeep را باز کنید، Run workflow و شاخهٔ master را انتخاب کنید. پس از موفقیت، artifact با نام botkeep-upload را از همان اجرا دانلود و استخراج کنید؛ در صورت وجود botkeep-upload.zip داخل آن، آن را نیز استخراج کنید. سه فایل باید مستقیماً در ریشهٔ سرور قرار بگیرند. این گردش کار باید دستی اجرا شود؛ انتشار فایل آن را خودکار اجرا نمی‌کند.
4. فایل شروع را main.py انتخاب کنید؛ اگر پنل فرمان اجرا می‌گیرد، python main.py را قرار دهید. Python 3.11 یا جدیدتر انتخاب کنید. requirements.txt عمداً فقط توضیح دارد و هیچ بستهٔ pip لازم نیست.
5. در صورت دسترسی به ترمینال، از ریشهٔ همین پروژه برای یک دریافت واقعی اختیاری اجرا کنید:

```sh
python main.py --once
```

سپس برای اجرای مداوم:

```sh
python main.py
```

هنگام اجرای آزمایش، نسخهٔ مداوم همین پروژه نباید هم‌زمان فعال باشد. دو نسخه را روی یک CSV یا مسیر خروجی مشترک اجرا نکنید. سرور قبلی می‌تواند مستقل و با فایل‌های خروجی جدا ادامه دهد.

## خروجی، پشتیبان و خطا

- prices.csv و monitor.log در کنار همین main.py ساخته می‌شوند؛ پوشه باید قابل نوشتن باشد. لاگ روی کنسول نیز نمایش داده می‌شود.
- CSV در حدود 5MiB به فایل زمان‌دار prices.<timestamp>.csv منتقل می‌شود؛ آرشیوها خودکار حذف نمی‌شوند. لاگ در حدود 1MB می‌چرخد و دو نسخهٔ قدیمی نگه می‌دارد. فایل‌های prices*.csv و monitor.log* را مرتب دانلود و فضای دیسک را بررسی کنید؛ ماندگاری داده بعد از restart را از میزبان بپرسید.
- --output مسیر CSV را تغییر می‌دهد؛ مسیر نسبی نسبت به پوشهٔ کاری است. لاگ همچنان کنار main.py می‌ماند.
- HTTP 401، 403 یا 451 باعث توقف می‌شود؛ محدودیت‌ها را دور نزنید. خطاهای دیگر با فاصلهٔ افزایشی دوباره امتحان می‌شوند؛ --once در خطا با کد 1 خارج می‌شود. دریافت موفق یک نمونه، تضمین تداوم سرویس یا سودآوری نیست.
- این اسکریپت وب‌سرور و پورت شنونده ندارد و برای خودش به پورت نیاز ندارد. ممکن است میزبان الزام HTTP/health check، محدودیت اجرای پس‌زمینه، اینترنت یا منابع داشته باشد؛ سازگاری و سیاست فعلی Botkeep و پذیرش Coinbase برای موقعیت شما بررسی یا تأیید نشده است.
- فایل‌های CSV و لاگ واقعی، توکن، رمز یا اطلاعات کیف پول را در مخزن عمومی بارگذاری نکنید. این بسته هیچ دادهٔ کاربر را همراه ندارد.

## وضعیت آزمایش

این بسته هنگام انتشار اجرا یا روی Botkeep آزمایش زنده نشده است. گردش کار بسته‌بندی فقط py_compile و ساخت ZIP با کتابخانهٔ استاندارد را انجام می‌دهد و درخواست قیمت نمی‌فرستد. موفقیت آن را پس از اجرای دستی بررسی کنید؛ آزمون اتصال واقعی فقط با اجرای خود برنامه انجام می‌شود.
