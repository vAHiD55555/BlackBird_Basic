# BlackBird_Basic

پایه‌ای سبک و قابل‌فهم برای **جمع‌آوری فقط‌خواندنی قیمت رمزارز و بررسی کیفیت CSV**، مناسب مدیریت با موبایل و میزبانی محدود.

**این پروژه فعلاً بات معامله‌گر یا مدل هوش مصنوعی نیست.** سفارش نمی‌فرستد، کیف پول متصل نمی‌کند، سود تضمین نمی‌کند و به کلید API نیاز ندارد. هدف این فاز، اطمینان از دریافت و نگهداری داده پیش از هر شبیه‌سازی است.

## نصب مستقل روی پروژهٔ تازهٔ Botkeep

برای آپلود ساده با موبایل، [بستهٔ مستقل deploy/botkeep](deploy/botkeep/) آماده است. **محتویات این پوشه** را در ریشهٔ یک پروژهٔ Python تازه بارگذاری کنید: main.py، requirements.txt و README_FA.md. این main.py مستقل است و collector/ نمی‌خواهد؛ فایل شروع main.py و فرمان، در صورت نیاز، python main.py --interval 60 است. سرور قبلی را دست‌نخورده نگه دارید و خروجی مشترک استفاده نکنید.

[راهنمای فارسی آپلود، پشتیبان و محدودیت‌ها](deploy/botkeep/README_FA.md) را بخوانید. برای ZIP کوچک، Actions → Package Botkeep → Run workflow روی master؛ بعد از موفقیت artifact به نام botkeep-upload را دانلود و ZIP را استخراج کنید. این گردش کار فقط بررسی نحوی و بسته‌بندی می‌کند و در این گفتگو اجرا نشده است؛ هیچ درخواست قیمت ارسال نمی‌کند.

## قابلیت‌های فعلی

- تلاش برای دریافت BTC-USD، ETH-USD، SOL-USD، XRP-USD، DOGE-USD و ADA-USD از API عمومی Coinbase Exchange؛ پشتیبانی و دسترسی فعلی هر جفت بررسی زنده نشده است
- چرخهٔ اسمی 60 ثانیه؛ --interval 30 نیز قابل انتخاب است. شش درخواست ترتیبی‌اند و هم‌زمانی یا تضمین فاصلهٔ دقیق ندارند
- ذخیرهٔ زمان دریافت UTC، زمان منبع، جفت و قیمت در همان CSV چهارستونی؛ موفقیت‌ها حتی در شکست بقیه حفظ می‌شوند
- لاگ چرخشی، timeout، تلاش مجدد در چرخهٔ بعد؛ 404 غیرفعال‌کردن جفت تا پایان اجرا، 429 مکث سراسری و 401/403/451 توقف کامل
- تحلیل آفلاین رکوردهای نامعتبر، زمان‌های تکراری، ترتیب و فاصلهٔ دریافت و خلاصهٔ قیمت، جدا برای هر جفت
- تست‌های آفلاین با دادهٔ کاملاً ساختگی و مشخص‌شده، فقط برای صحت کد
- GitHub Actions با اجرای دستی برای تست و گزارش JSON از CSV کوچک ورودی

## ساختار

```text
main.py                       ورودی میزبان نسخهٔ پوشه‌بندی‌شده
collector/monitor.py          دریافت و ذخیرهٔ شش جفت
 deploy/botkeep/              نسخهٔ مستقل و راهنمای آپلود
 tools/analyze_prices.py      تحلیل کیفیت CSV
 tests/test_analysis.py       تست تحلیل بدون اینترنت
 tests/test_monitor.py        تست جمع‌آورنده با mock
 docs/SETUP_FA.md             راهنمای کامل فارسی
 data/                        محل اختیاری داده‌های محلی
 reports/                     گزارش‌های محلی
 .github/workflows/analyze.yml اجرای دستی تحلیل
 .github/workflows/package-botkeep.yml بسته‌بندی دستی
 requirements.txt             بدون وابستگی خارجی
```

فاصلهٔ ابتدای بعضی خطوط در نمایش بالا فقط برای خوانایی است؛ نام پوشه‌ها فاقد فاصله است. تصویر موجود مخزن دست‌نخورده باقی مانده است.

## شروع سریع

Python 3.11+ لازم است؛ نصب بستهٔ اضافی لازم نیست.

```sh
# یک چرخهٔ واقعی شش جفت، نه آزمون تداوم؛ در شکست جزئی خروجی غیرصفر
python main.py --once

# جمع‌آوری مداوم؛ پیش‌فرض نیز 60 است؛ با Ctrl+C متوقف می‌شود
python main.py --interval 60

# گزینهٔ 30 ثانیه؛ تضمین دسترسی یا پذیرش نرخ نیست
python main.py --interval 30

# تحلیل دادهٔ 60 ثانیه‌ای، بدون تماس شبکه
python tools/analyze_prices.py prices.csv --expected-interval 60 --output reports/analysis.json

# CSV قدیمی با فاصلهٔ اسمی پنج دقیقه
python tools/analyze_prices.py old-prices.csv --expected-interval 300

# اجرای تست‌های آفلاین
python -m unittest discover -s tests -v
```

اگر main.py ریشهٔ مخزن را استفاده می‌کنید، کل پوشهٔ collector باید همراه آن بارگذاری شود. برای پروژهٔ تازهٔ Botkeep، به‌جای آن از main.py مستقل در [deploy/botkeep](deploy/botkeep/) استفاده کنید. اجرای فعلی مستقل شما را برای استفاده از تحلیل‌گر تغییر ندهید. جزئیات نسخهٔ پوشه‌بندی‌شده در [راهنمای نصب و رفع خطا](docs/SETUP_FA.md).

گزارش JSON اکنون از gaps_over_threshold_seconds به‌جای gaps_over_330_seconds استفاده می‌کند؛ expected_interval_seconds و gap_threshold_seconds نیز اضافه شده‌اند. آستانه 1.1 برابر فاصلهٔ انتخابی است: 66 ثانیه برای 60 و 330 برای 300. CSV چهارستونی قبلی تغییر نکرده است. برای تغییر نرخ، فایل خروجی تازه انتخاب کنید یا دوره‌های قدیم و جدید را جدا تحلیل کنید؛ یک مقدار فاصله برای فایل با نرخ مخلوط کافی نیست.

## اجرای تحلیل فقط با مرورگر GitHub

Actions → Analyze CSV manually → Run workflow؛ expected_interval را 60، 30 یا برای فایل قدیمی 300 انتخاب کنید. متن CSV غیرحساس را همراه سطر عنوان وارد کنید. ورودی خالی یک چرخهٔ واقعی شش جفت را امتحان می‌کند؛ شکست دسترسی می‌تواند زودتر متوقف کند. گزارش از Artifacts همان اجرا دریافت می‌شود. هیچ فایل بازار یا گزارش واقعی کاربر همراه مخزن منتشر نشده است. محدودیت‌های ورودی موبایل و حریم خصوصی در راهنما آمده است.

## امنیت و محدودیت‌ها

- مخزن عمومی است. رمز، توکن، عبارت بازیابی، کلید خصوصی و دادهٔ حساب را منتشر نکنید.
- .gitignore پشتیبان امنیتی کامل نیست؛ بارگذاری دستی را جدا بررسی کنید.
- تنها منبع فعلی Coinbase است؛ پذیرش حقوقی سرویس برای اقامت/موقعیت شما در این پروژه تأیید نشده است. دسترسی فنی به معنی مجازبودن استفاده نیست؛ محدودیت‌ها را دور نزنید.
- قیمت نمونه‌برداری‌شده کندل، عمق بازار یا تضمین قیمت اجرای سفارش نیست؛ نرخ 30 یا 60 ثانیه نیز آزمون فشار بازار یا پیش‌بینی نوسان نیست.
- تغییر قیمت، سود استراتژی نیست؛ هیچ کارمزد، لغزش قیمت یا معامله‌ای شبیه‌سازی نشده است.
- هر درخواست timeout بیست‌ثانیه‌ای دارد؛ شبکه، پردازش و مکث نرخ می‌توانند فاصله‌ها را طولانی‌تر کنند. چرخه‌ها هم‌پوشانی ندارند و عقب‌افتادگی با هجوم درخواست جبران نمی‌شود.
- پایداری میزبان، حفظ داده پس از restart، سقف منابع و پذیرش کاربران را جدا بررسی کنید.
- GitHub Actions سرور دائمی نیست و در این پروژه برای جمع‌آوری دائمی استفاده نمی‌شود.

## وضعیت آزمایش

نسخهٔ مستقل قبلی جمع‌آورنده با فایل‌های ارسالی کاربر بررسی شده بود. نسخهٔ شش‌جفتی، تحلیل‌گر و تست‌های تازه در این گفتگو اجرا نشده‌اند و روی Botkeep نیز آزمایش نشده‌اند. وجود تست به معنی موفقیت اجرای تست نیست؛ نتیجهٔ واقعی را پس از اجرا بررسی کنید.

## مراحل بعدی، خارج از نسخهٔ فعلی

1. اجرای تست و بررسی گزارش واقعی، بدون تغییر جمع‌آورندهٔ فعال
2. طراحی معاملات فرضی با قواعد و هزینه‌های مشخص
3. در صورت درخواست، انتقال امن داده و تحریک پردازش از میزبان

فعلاً webhook، اجرای خودکار معاملات، مدل هوش مصنوعی و اتصال Ollama پیاده‌سازی نشده‌اند. هیچ کلیدی برای این نسخه لازم نیست.
